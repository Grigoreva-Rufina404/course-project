# Курсовой проект:  Разработка программного игрового приложения на основе сюжетов музыкальных композиций группы «Король и Шут»

**Группа:** ПИ-51
**Дисциплина:** Объектно-ориентированное программирование

## Цель: 
Предоставить пользователю развлекательное игровое приложение, позволяющее проходить сюжетную игру с выполнением заданий, исследованием игрового мира, взаимодействием с персонажами, сражениями и принятием решений, влияющих на развитие событий. Программа предназначена для пользователей, заинтересованных в сюжетных ролевых играх.

## Лабораторная работа № 3

В рамках лабораторной работы реализованы версии игровой модели на языках Java и C++. Работа посвящена управлению временем жизни объектов, ссылкам и автоматическому освобождению ресурсов.

### Структура проекта

- `lab-03/java/src/` — реализация на Java.
- `lab-03/cpp/src/` — реализация на C++.

### Сборка и запуск Java-версии

Перейти в каталог исходных файлов:

```bash
cd lab-03/java/src
```

Скомпилировать программу:

```bash
javac -encoding UTF-8 *.java
```

Запустить программу:

```bash
java Main
```

Если в системе используются разные версии Java, необходимо выбрать совместимые версии `javac` и `java`.

### Сборка и запуск C++-версии

Перейти в каталог исходных файлов:

```bash
cd lab-03/cpp/src
```

Скомпилировать программу с использованием стандарта C++17:

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic Item.cpp Inventory.cpp Player.cpp main.cpp -o lab03_cpp.exe
```

Запустить программу в Git Bash:

```bash
./lab03_cpp.exe
```

### Основные элементы реализации

**Java:**
- работа с объектами и ссылками;
- демонстрация нескольких ссылок на один объект;
- использование `WeakReference`;
- автоматическое закрытие ресурсов с помощью `AutoCloseable` и `try-with-resources`.

**C++:**
- использование `std::unique_ptr`, `std::shared_ptr` и `std::weak_ptr`;
- управление временем жизни объектов без ручного применения `new` и `delete`;
- применение умных указателей для динамического массива;
- демонстрация автоматического вызова деструкторов.
